## 📁 Highlighted Open-Source Projects

### [⚙️ IEC 61131-3 Simple Conveyor PLC Control](https://github.com/alexkitaa/simple-conveyor)
A Structured Text (ST) IEC 61131-3 PLC program designed for **OpenPLC Runtime v4**.
- Implements a **latched conveyor motor control system** driven by HMI start/stop pushbuttons.
- Features a **rising-edge item counter** alongside a built-in **timer-based sensor simulator** for standalone logic validation without physical field hardware.

### [🔍 Modbus TCP Traffic Sniffing & Manipulation Lab](https://github.com/alexkitaa/manipulating-modbus_tcp)
An offensive OT lab demonstrating how to capture, dissect, and manipulate unencrypted industrial control system (ICS) network traffic.
- Built around **OpenPLC Runtime v4**, `mbpoll`, and **Wireshark** across an isolated virtualized lab environment.
- Executes the [Simple Conveyor PLC program](https://github.com/alexkitaa/simple-conveyor) as a live target, exposing realistic process variables, coils, and holding registers for protocol interrogation and unauthorized state manipulation.
